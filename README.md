## What I like to build

### Data pipelines and ETL workflows
I enjoy designing workflows that move data from raw sources to clean analytical outputs. My focus is not only moving data, but making sure it arrives structured, traceable, and ready for use.

### SQL validation and reconciliation
I use SQL to compare sources, validate business rules, detect inconsistencies, investigate missing records, and create auditable logic for reporting and decision-making.

### BI dashboards and reporting
I build dashboards that help stakeholders understand KPIs, trends, operational indicators, financial data, and process performance with clarity.

### Python automation
I use Python to automate repetitive data tasks, clean files, process Excel/CSV datasets, interact with APIs, and create repeatable reporting workflows.

## Engineering principles

**Data quality first**  
A dashboard is only useful if the underlying data is reliable. I care about validation, consistency, traceability, and business rules.

**Business context matters**  
Data work is not only technical. Understanding the business problem is essential to build useful queries, dashboards, pipelines, and reports.

**Automation reduces risk**  
Manual work creates inconsistency. When a task becomes repetitive, I look for ways to script, document, and automate it.

**Readable code and documentation**  
Good projects should be understandable by other people. I value clean structure, clear naming, useful comments, and practical documentation.
